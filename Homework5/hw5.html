Exercise 1

Riemann and Lebesgue integration

For a function f on [a, b] I approximate I = ∫f in two ways: by partitioning the domain (Riemann) and by partitioning the range of values (Lebesgue). The pathological functions are treated in 1.3.

1.1

Riemann and Lebesgue sums

Riemann. The domain is split into N subintervals of width h = (b − a)/N and f is evaluated at their midpoints:

RN = h ∑i=1…N f(a + (i − ½)h)

Lebesgue. The range [y0, yK], from the minimum to the maximum of f, is split into K levels yj = y0 + jΔ, and each level is weighted by the measure of its preimage Ej = f−1([yj, yj+1)):

LK− = ∑ yj μ(Ej) ≤ I ≤ LK+ = ∑ yj+1 μ(Ej),   LK = (LK− + LK+)/2

The gap LK+ − LK− = Δ(b − a) does not depend on how irregular f is. On a computer μ(Ej) also has to be approximated: I use a grid of P = 1,000,000 cells of length (b − a)/P and add up the cells whose midpoint value falls in [yj, yj+1).

Riemann: N = 8 subintervals of the domain

Lebesgue: K = 8 levels of the range

1.3

Pathological functions

Every floating-point number is rational, so the Dirichlet function D and Thomae's function T cannot be evaluated by testing x. I choose the tags of the Riemann sums explicitly: rational tags xi = (2i − 1)/(2N), where D = 1 and T = 1/q after reducing the fraction, or irrational tags xi = (i − 1 + 1/√2)/N, where D = T = 0.

The Lebesgue integral only needs measures. ℚ ∩ [0, 1] is countable: covering its r-th element with an interval of length ε/2r gives total length at most ε, so μ(ℚ ∩ [0, 1]) = 0. Then D = T = 0 almost everywhere and ∫D = ∫T = 0, for every K.

1.4

Conclusions

Accuracy and convergence. For smooth functions the Riemann error falls like 1/N²: for sin x from 8.2e-3 at N = 10 to 8.2e-11 at N = 100,000. The Lebesgue error falls more slowly, about like K−3/2 (from 1.7e-2 to 1.8e-8), because near the maximum and the minimum, where f′ = 0, a single level contains a large part of the domain. On the other hand the Lebesgue bound Δ(b − a) holds for any bounded f, while the Riemann error depends on smoothness: a jump inside a subinterval gives an error of order h (for the 1/3 step function and N = 1,001 it is ). With N even the jump and the kink of |x − 0.5| are grid nodes and the midpoint rule is exact. The Lebesgue sum of a step function only needs the measures of the preimages of its values, so it is exact for every K.

Efficiency. RN costs N evaluations of f. LK costs P evaluations to measure the preimages, plus P + K operations, whatever K is. For sin x the Riemann sum reaches 8.2e-9 with N = 10,000 in , while the Lebesgue sum needs K = 100,000 for 1.8e-8, in . In practice the hard part of the Lebesgue approach is measuring the preimages.

Same limit. For the Riemann-integrable functions (all the examples except 1/√x and D) both sums converge to the exact value, as the theory says: a Riemann-integrable function is also Lebesgue integrable, with the same integral. Thomae's function is discontinuous at every rational number but still Riemann integrable: its sums go to 0 slowly (2.9e-6 at N = 106) and agree with the Lebesgue value 0.

Different behaviour. 1/√x is unbounded, so it is not Riemann integrable in the proper sense. The midpoint sums of the improper integral converge slowly, with error about 0.6/√N. With equally spaced levels the Lebesgue sum is very poor for small K (error 70 at K = 10): the sampled range is [1, 1,414] and almost all the measure lies in the lowest level. It improves only for large K and stops at the accuracy of the grid (5.7e-4). The Dirichlet function is the clearest case: its Riemann sums are 1 or 0 depending on the tags, so they have no limit and D is not Riemann integrable, while its Lebesgue integral is simply 0.

Exercise 2

Numerical computation of the normal CDF

Φ(x) = P(Z ≤ x) = ∫−∞x φ(t) dt with φ(t) = e−t²/2/√(2π). The integral over the whole line equals 1 (with polar coordinates, Hogg, McKean, Craig §3.4), but for a finite x there is no formula with elementary functions.

2.1

Why Φ is not elementary: Liouville's theorem

Liouville's theorem, in the form used for integrands f eg: if f and g are rational functions, g not constant, and ∫ f eg dx is elementary, then

∫ f eg dx = R eg + C,   R rational, i.e. f = R′ + g′R

For e−t²/2 we have f = 1 and g = −t²/2, so we would need a rational R with R′ − tR = 1. This is impossible:

  • if R is a polynomial of degree d, tR has degree d + 1 and R′ degree d − 1, so R′ − tR has degree d + 1 ≥ 1 and is not the constant 1 (and R = 0 gives 0);
  • if R has a pole of order k ≥ 1 at some c, then R′ has a pole of order k + 1 there, while tR has order at most k and 1 has none.

So e−t²/2 has no elementary antiderivative, and neither has Φ(x) = ½ + ∫0x φ(t) dt.

2.2

The error function

erf(z) = (2/√π) ∫0z e−s² ds,   Φ(x) = ½[1 + erf(x/√2)]

The second identity follows from t = √2 s and is an exact representation of Φ: erf is a new function, defined by that integral, with known properties (it is odd, erf(∞) = 1, it has series and asymptotic expansions). But giving the integral a name does not give its digits. Like sin or exp, erf has to be computed by an algorithm, and JavaScript does not even have Math.erf, so every method below is written by hand.

2.3

Numerical methods

  • Simpson's rule on ½ + ∫0x φ with n subintervals, error O(h4), h = x/n.
  • Power series of erf:
    erf(z) = (2/√π) ∑k≥0 (−1)k z2k+1/(k! (2k + 1))
    It converges for every z, but the terms alternate in sign and grow up to about ez² before decreasing, so for large z the digits cancel.
  • Abramowitz–Stegun 7.1.26: erf(z) ≈ 1 − (a1t + … + a5t5) e−z², t = 1/(1 + pz), with fixed constants and error at most 1.5 · 10−7.

My method combines two expansions chosen so that no subtraction of close numbers happens:

  • |x| < 2.5: S(x) = ex²/2 ∫0x e−t²/2 dt satisfies S′ = xS + 1, S(0) = 0, which gives a series whose terms all have the same sign:
    Φ(x) = ½ + φ(x) ∑k≥0 x2k+1/(1 · 3 · … · (2k + 1))
  • |x| ≥ 2.5: the tail has Laplace's continued fraction, with a = |x|,
    1 − Φ(a) = φ(a)/(a + 1/(a + 2/(a + 3/(a + …))))
    evaluated with Lentz's algorithm until the relative change is below 10−16. For x < 0 this is Φ(x) itself, so the left tail keeps full relative precision. 
function normcdf(x) {
  const a = Math.abs(x);
  if (a < 2.5) {
    let t = x,
      s = x;
    for (let k = 1; Math.abs(t) > 1e-17 * Math.abs(s); k++) {
      t *= (x * x) / (2 * k + 1);
      s += t;
    }
    return 0.5 + phi(x) * s;
  }
  let f = a,
    c = a,
    d = 0;
  for (let k = 1; k < 500; k++) {
    d = 1 / (a + k * d);
    c = a + k / c;
    f *= c * d;
    if (Math.abs(c * d - 1) < 1e-16) break;
  }
  const tail = phi(a) / f;
  return x < 0 ? tail : 1 - tail;
}

2.5

Conclusions

Accuracy. My method agrees with the reference within its uncertainty at every point, and in the left tail its relative error is below the precision of the reference. The erf series is exact for small x but loses digits by cancellation as x grows (error at x = 8). Abramowitz–Stegun has a uniform error of about 10−7, and Simpson's error falls like n−4. All the formulas of the type ½ + something lose the left tail, because they compute a tiny number as the difference of two numbers close to ½.

Efficiency. Abramowitz–Stegun is the fastest () but gives only 7 digits. My method gives full double precision in with at most about 70 terms. Simpson's rule needs n evaluations of φ per point, and the erf series needs more and more terms as |x| grows.

Why numerical methods are still needed. erf gives an exact closed form for Φ, but evaluating erf still requires one of these algorithms. Numerical libraries do the same, with series, continued fractions and rational approximations on different ranges of x.

Homework 6 · Statistical independence

Contingency tables & independence

I build the contingency table of a bivariate dataset, compare it with the frequencies expected under independence through the χ² statistic and discuss what the result means.

Tommaso Tabacchini( Student ID: 1934387 )

Dataset

Graduate admissions at UC Berkeley, 1973

Applicants to the six largest departments in fall 1973 (Bickel, Hammel, O'Connell, Science 1975; dataset UCBAdmissions in R): 4,526 people, each with X = gender (Male, Female), F = admission (Admitted, Rejected) and the department applied to. The analysis can be repeated for a single department.

1

Contingency table

The data are distributed as counts, so I first expand them into one record per applicant. From there on the code only sees a list of pairs (x, f), as for any raw bivariate dataset: it finds the levels of the two variables, counts the joint frequencies nij, the marginal totals and the expected frequencies, and adds up χ².

Joint frequencies nij and marginal totals

Relative frequencies fij = nij/n

function contingency(pairs) {
  const xs = [...new Set(pairs.map((p) => p[0]))],
    fs = [...new Set(pairs.map((p) => p[1]))];
  const n = xs.map(() => fs.map(() => 0));
  for (const [x, f] of pairs) n[xs.indexOf(x)][fs.indexOf(f)]++;
  const row = n.map((r) => r.reduce((a, b) => a + b, 0)),
    col = fs.map((_, j) => n.reduce((a, r) => a + r[j], 0)),
    tot = row.reduce((a, b) => a + b, 0),
    exp = row.map((ri) => col.map((cj) => (ri * cj) / tot));
  let chi2 = 0;
  for (let i = 0; i < xs.length; i++)
    for (let j = 0; j < fs.length; j++)
      chi2 += (n[i][j] - exp[i][j]) ** 2 / exp[i][j];
  const df = (xs.length - 1) * (fs.length - 1);
  return { xs, fs, n, row, col, tot, exp, chi2, df };
}

Marginal and conditional frequencies

The marginal frequencies are the last row and column of the relative table, fi· = ni·/n and f·j = n·j/n. The conditional frequencies divide each cell by its row or its column total:

f(F = j | X = i) = nij/ni·,   f(X = i | F = j) = nij/n·j

If the variables were independent, every row of the first table would equal its last row (the marginal of F), and every column of the second table would equal its last column.

Expected frequencies and χ²

Under independence fij = fi·f·j, so the expected count of each cell is

Eij = ni· n·j / n,   χ² = ∑i,j (nij − Eij)² / Eij

Under the hypothesis of independence χ² has approximately a chi-square distribution with (r − 1)(c − 1) degrees of freedom, if all Eij ≥ 5. The p-value is P(χ²df ≥ χ²), the regularized upper incomplete gamma function Q(df/2, χ²/2), which I compute with a series for small arguments and a continued fraction for large ones (as for the normal tail in Homework 5).

Independence in probability and in statistics

Probability. Two events are independent if P(A ∩ B) = P(A)P(B). Two discrete random variables are independent if P(X = x, F = y) = P(X = x)P(F = y) for all x, y, or equivalently P(F = y | X = x) = P(F = y): knowing X does not change the distribution of F. It is a property of the model, exact by definition.

Statistics. On observed data the variables are independent if fij = fi·f·j in every cell, i.e. nij = Eij and all conditional distributions coincide with the marginal one. In a sample this practically never holds exactly, so the question becomes whether the deviations are larger than chance would give if the variables were independent in the population. This is what the χ² test measures: χ² = 0 means perfect empirical independence, and a small p-value means that deviations as large as the observed ones would be very unlikely under independence.

Interpretation

Repeating the test department by department:

Only department A has a significant dependence, and there women are admitted more often than men (82% against 62%). In the other five departments the two admission rates are close and independence is not rejected.

6

Conclusions: association and causality

In the aggregate data gender and admission are clearly statistically dependent: 44.5% of men and 30.4% of women were admitted, and the χ² test rejects independence with p ≈ 8 · 10−22. This is an association, not a proof that gender causes rejection.

The department is a third variable associated with both. 93% of the women applied to departments C–F, which admit between 6% and 35% of their applicants, while more than half of the men applied to A and B, which admit more than 60%. Within each department, where this variable is fixed, the dependence almost disappears, and in A it even goes in the opposite direction. The aggregate association is produced by where people applied (Simpson's paradox), not by how each department treated men and women.

A χ² test only says whether two variables are associated. To speak of causality one has to control the other variables that could explain the association, for example by stratifying as above or, when possible, with a randomized experiment. Also, a small p-value says that an association exists, not that it is large: with 4,526 observations even modest differences become significant, so the conditional frequencies are needed to judge its size.

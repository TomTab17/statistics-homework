Exercise 1

Modes of convergence in probability theory

X1, X2, … and X are random variables on the same probability space (Ω, 𝓕, P). The four modes differ in what is required to become small: the error on every single outcome ω, the probability of a large error, the mean squared error, or only the distribution.

1.1

The four modes

  • Almost sure: P({ω : Xn(ω) → X(ω)}) = 1. Every trajectory converges, except a set of probability 0.
  • In probability: P(|Xn − X| > ε) → 0 for every ε > 0. For each large n a big error is unlikely, but along a trajectory it can still happen infinitely often.
  • In mean square (L²): E[(Xn − X)²] → 0. It controls the size of the error, not only its probability, and needs finite second moments.
  • In distribution: FXn(x) → FX(x) at every continuity point of FX. Only the laws are compared: the variables need not even be defined on the same space.
a.s. ⇒ in probability ⇒ in distribution
L² ⇒ in probability
in distribution to a constant ⇒ in probability

L² implies convergence in probability by Chebyshev: P(|Xn − X| > ε) ≤ E[(Xn − X)²]/ε². No other arrow holds:

  • in probability, not a.s.: independent Xn ~ Bernoulli(1/n). P(Xn = 1) = 1/n → 0 (and E[Xn²] = 1/n, so also L²), but ∑ 1/n = ∞ and by the second Borel–Cantelli lemma Xn = 1 infinitely often with probability 1;
  • a.s., not L²: U ~ Uniform(0, 1), Xn = n · 1{U < 1/n}. Xn(ω) = 0 as soon as n > 1/U, but E[Xn²] = n → ∞;
  • in distribution, not in probability: X ~ N(0, 1), Xn = −X. Same law for every n, but |Xn − X| = 2|X| does not shrink.
1.2

Role in the LLN, the CLT and inference

Let X1, X2, … be i.i.d. with mean μ and variance σ², and x̄n = Sn/n.

  • L²: E[(x̄n − μ)²] = Var(x̄n) = σ²/n → 0.
  • Weak LLN: x̄n → μ in probability. With finite variance it follows from L² and Chebyshev, P(|x̄n − μ| > ε) ≤ σ²/(nε²).
  • Strong LLN (Kolmogorov): x̄n → μ almost surely, if only E|X| < ∞. It says that along one infinite sequence of trials the running mean converges, which justifies reading long-run frequencies as probabilities (first figure).
  • CLT: Zn = √n(x̄n − μ)/σ → N(0, 1) in distribution, and only in distribution: Z2n = (Zn + Z′n)/√2 with Z′n independent of Zn, so Z2n − Zn does not go to 0. The values keep fluctuating, only their law stabilizes (second figure, with a very skewed X).

In statistics, a consistent estimator is one that converges in probability to the parameter (e.g. s² → σ²). Slutsky's theorem mixes the modes: if Zn → Z in distribution and Yn → c in probability, then YnZn → cZ. This is why s can replace σ: √n(x̄n − μ)/s → N(0, 1), the basis of large-sample tests and confidence intervals. The delta method, the asymptotic normality of maximum likelihood estimators and the Glivenko–Cantelli theorem (the empirical CDF converges uniformly to F, almost surely) are built the same way.

1.3

Why √n

The variance of a sum is Var(Sn) = ∑ Var(Xi) + 2 ∑i<j Cov(Xi, Xj). If the Xi are independent (uncorrelated is enough) the covariances vanish and variance is additive, Var(Sn) = nσ². Standard deviations are not additive: the sum grows like n but its fluctuation only like σ√n, because independent errors partly cancel. Hence sd(x̄n) = σ/√n.

So x̄n − μ is of order 1/√n: na(x̄n − μ) goes to 0 for a < ½ and blows up for a > ½. Only a = ½ gives a non-degenerate limit, which is exactly the CLT. In inference the same factor gives the standard error s/√n, the interval x̄ ± z s/√n, the statistic t = √n(x̄ − μ0)/s and the sample size n = (zσ/E)² for a margin E: halving the error needs four times the data.

Independence is what makes this work. If all pairs have correlation ρ > 0, then Var(x̄n) = σ²[1/n + (1 − 1/n)ρ] → σ²ρ: there is no rate and no LLN (with ρ = 0.1 the standard deviation never goes below 0.32σ). Weak dependence, with correlations that die out quickly, keeps the √n rate but changes the constant (effective sample size). Without a finite variance the rate changes too: for the Cauchy distribution x̄n has the same law as X1 for every n.

Exercise 2

Conditional probability, Bayes and inference

Conditional probability is how probabilities change when information arrives. Bayes' theorem turns it into a rule for learning about unknown parameters from data.

2.1

Conditional probability

In probability theory, for P(B) > 0,

P(A | B) = P(A ∩ B) / P(B)

is a new probability measure concentrated on B. It gives the multiplication rule P(A ∩ B) = P(A | B)P(B), the law of total probability P(A) = ∑ P(A | Bk)P(Bk) for a partition, and independence as P(A | B) = P(A).

In statistics what we condition on is the observed data x. A model gives f(x | θ), the probability of the data for each value of the parameter. Frequentist inference keeps θ fixed and unknown, uses L(θ; x) = f(x | θ) as a function of θ (maximum likelihood) and judges procedures over repeated samples. Bayesian inference treats θ as a random variable and asks for P(θ | x): the conditioning has to be reversed, and Bayes' theorem does it.

2.2

Bayes' theorem

P(H | E) = P(E | H) P(H) / P(E),   P(E) = ∑k P(E | Hk) P(Hk)

For a parameter with density, given data x:

π(θ | x) = L(θ; x) π(θ) / ∫ L(θ′; x) π(θ′) dθ′ ∝ L(θ; x) π(θ)

Updating. The posterior after x1 is the prior for x2: π(θ | x1, x2) ∝ f(x2 | θ) π(θ | x1), the same as using both data at once (for conditionally independent data). This is why the process is central in Bayesian inference: the posterior contains everything, and every answer comes from it: point estimates (posterior mean, mode), credible intervals with P(θ ∈ I | x) = 0.95 read literally, predictions for new data, decisions that minimize expected loss.

  • Prior π(θ): what is known about θ before the data (previous studies, physical constraints, or only vague bounds).
  • Likelihood L(θ; x) = f(x | θ): how probable the observed data are for each θ. It carries all the information of the data and is not a distribution on θ (it need not integrate to 1).
  • Posterior π(θ | x): the prior reweighted by the likelihood and normalized. Values of θ that explain the data well gain weight, the others lose it.
  • Evidence P(x): the normalizing constant. It does not change the shape of the posterior, but it is what compares different models.
2.3

Example 1: a diagnostic test

A disease has prevalence p: this is the prior P(D). A test has sensitivity P(+ | D) = 0.99 and specificity P(− | not D) = 0.95: these are the likelihoods of a positive result under the two hypotheses. After a positive result

P(D | +) = 0.99p / [0.99p + 0.05(1 − p)]

With p = 1% a positive test gives only 16.7%: among 10,000 people, 99 true positives against 495 false positives from the 9,900 healthy ones. The likelihood is the same in every row of the table, only the prior changes, and it turns a probable false alarm into an almost sure diagnosis. A second independent positive test uses 16.7% as its prior and gives 79.8%.

2.4

Example 2: estimating a success probability

θ is the probability that an attack succeeds (as in Homework 3), and the data are k successes in n independent attempts, so L(θ) ∝ θk(1 − θ)n−k. With a Beta(a, b) prior the posterior is again a Beta (conjugate prior):

π(θ | k) = Beta(a + k, b + n − k),   E[θ | k] = (a + k)/(a + b + n)

The posterior mean is a weighted average of the prior mean a/(a + b) and of the observed frequency k/n, with weights a + b and n: the prior counts as a + b extra observations. The data have k = 0.7n; the three priors are flat, centered on 0.5, and wrong (mean 0.1).

2.5

Advantages, limitations and influence on the conclusions

Advantages. Prior knowledge enters explicitly instead of informally. The answer is a probability statement about the parameter, so a credible interval means what people usually think a confidence interval means. Updating is coherent and sequential, and the method works with few data: with a flat prior, 0 successes in 3 attempts give a posterior mean of 0.2, not the estimate 0 of maximum likelihood.

Limitations. The prior is a choice, and with few data the conclusions depend on it: with n = 10 the three posterior means are 0.67, 0.57 and 0.30. "Non-informative" priors are not unique (flat on θ is not flat on the log-odds). The evidence integral rarely has a closed form, so real models need numerical methods such as MCMC. If the likelihood (the model) is wrong, the posterior is wrong too, and a prior that gives probability 0 to the true value can never be corrected by data.

Influence on the conclusions. The weight of the prior is fixed, while the information in the likelihood grows with n and the posterior standard deviation shrinks like 1/√n, the rate of Exercise 1. With n = 1,000 the three posterior means are 0.700, 0.696 and 0.688 and the intervals almost coincide: the data dominate. In the diagnostic example the data are a single test, so the prior stays decisive. A Bayesian analysis should therefore state its prior and show how much the results change with other reasonable priors.
